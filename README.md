# Diego I. Perez Bakovic - Personal Portfolio

This repository contains the code for my personal portfolio website, built for ISYS 53203-002 - Development w/ Digital Innovation as part of the M.S. in Applied Business Analytics program at the University of Arkansas.

Specifically, this fulfills the Module 2 Assignment: Prototype Development. It includes my baseline AI-generated layout (Portfolio 1) and my refined, intentional design utilizing a "Royal Athletic" aesthetic and Santiago Bernabéu architectural motifs (Portfolio 2).
